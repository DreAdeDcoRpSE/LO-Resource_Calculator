# Last Oasis Resource Calculator

![Last Oasis Resource Calculator Banner](https://raw.githubusercontent.com/DreAdeDcoRpSE/lo-admin-tool-assets/refs/heads/main/lo-banner.jpg)

A web-based tool designed to help **Last Oasis** players calculate maximum base maintenance time and optimal resource stack allocation based on their storage capacity and daily upkeep costs.

## 🔗[CLICK HERE TO USE IT LIVE VIA GITHUB](https://dreadedcorpse.github.io/LO-Resource_Calculator/)

## 📖 About

Managing base maintenance in Last Oasis requires careful planning of resource storage. This calculator helps you determine exactly how long your base will survive based on the contents of your maintenance chest and the daily upkeep values shown in-game.

## ✨ Features

- **Custom Storage Capacity:** Support for various chest types (e.g., Gold Vault, Gigantic Chest).
- **Flexible Stack Sizes:** Accommodates different resource stack limits (200, 300, 500, etc.).
- **Multi-Resource Support:** Add multiple resources to calculate combined upkeep.
- **Optimal Allocation:** Determines the best way to fill storage for maximum uptime.
- **Export Results:** Save or share your calculation results.

## 🚀 How to Use

Follow these steps to calculate your base maintenance duration:

### Step 1: Download off of Git
 - Click the Code button at the top of this repository and select Download ZIP.
 - Extract the folder.
 - Locate lo_resource_calc.htm file and Double-click to open it in your preferred web browser (Chrome, Firefox, Edge, etc.).

### Step 2: Enter Total Storage Space
Input your maintenance chest's total storage capacity.
- **Example:** `50000` for a full gold vault.
- **Calculation Tip:** You can count each block and multiply by capacity, OR calculate:  
  `Total Rows × Total Columns × Stack Size`  
  *(e.g., 20 × 5 × 500 for a gold vault)*

### Step 3: Enter Items Per Stack
Input the stack size limit for the resources you are storing.
- **Example:** `500` for a Gigantic chest.
- **Note:** This is visible when you hover over or place the resource in-game.

### Step 4: Input Resources & Daily Costs
Open your **Base Maintenance Panel** in-game and enter the daily upkeep value for each resource.
- **Example:** If the panel shows `706` next to **Redwood**, enter `706`.
- Click **"+ Add Resource"** to include additional resources (Wood, Stone, Food, etc.).

### Step 5: Calculate
Click the **Calculate** button to view:
- Maximum maintenance time (in whole hours).
- Optimal stack allocation.

> **Note:** Results show whole hours (like the game) and use only full stacks.

## 🛠️ Controls

| Button | Action |
| :--- | :--- |
| **+ Add Resource** | Add a new resource row to the calculator. |
| **Calculate** | Run the calculation based on current inputs. |
| **Clear All** | Reset all fields to default. |
| **Export Results** | Save or share your calculation data. |
